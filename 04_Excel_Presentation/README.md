# Final Excel Presentation – Loan Analysis Dashboard

## Overview

This folder contains the final Excel presentation of the Loan Data Analysis Project. It showcases an interactive dashboard designed to present loan performance, borrower risk indicators, and default patterns in a clear and visually appealing format.

The dashboard consolidates key findings from the analysis into a single view, helping users understand the factors associated with loan defaults and evaluate credit risk against the company's target.

## Dashboard Components

### 1. Key Performance Indicators (KPIs)
- **Total Loans:** 601
- **Total Defaults:** 146
- **Highest DTI Default Rate:** 34.32%
- **Company Default Rate Target:** 12%

### 2. Loan Default Analysis

The dashboard includes four major visual analyses:

- **Default Rate by Loan Purpose:** Compares default rates across different loan categories to identify higher-risk purposes.
- **Default Rate by Credit Score Range:** Evaluates how creditworthiness relates to loan default behaviour.
- **Default Rate by Employment Time:** Highlights the relationship between employment stability and borrower defaults.
- **Default Rate by DTI:** Examines how Debt-to-Income ratios influence default risk across borrower segments.

### 3. Additional Risk Indicators

- Average DTI of Defaulted Loans: 57.87
- Average DTI of Non-Defaulted Loans: 47.05
- Company Default Rate Target: 12%

## Key Dashboard Insights

- The overall loan default rate is **24.29%**, exceeding the company target of 12%.
- Borrowers with credit scores between 520–599 show the highest default rate.
- Borrowers with a DTI ratio of 50% or above have a default rate of 34.32%.
- Borrowers with less than two years of employment show a higher default rate than those with longer employment tenure.
- Defaulted borrowers have a higher average DTI ratio than non-defaulted borrowers.

## Business Objective

To transform loan and borrower data into actionable credit risk insights through effective Excel dashboard visualization, helping identify high-risk borrower segments and supporting better lending decisions.
