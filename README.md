# Loan Data Analysis | Credit Risk & Default Analysis

## Project Overview

This project focuses on analyzing loan applications and borrower profiles to identify the key factors associated with loan defaults. Using Microsoft Excel and Power Query, two separate datasets were merged into a unified dataset to evaluate borrower risk and uncover patterns in loan repayment behaviour.

An interactive Excel dashboard was developed to present key performance indicators, default trends, and credit risk insights to support data-driven lending decisions.

## Business Problem

Which borrower and loan factors are most associated with loan defaults, and how can these insights help improve credit risk assessment?

## Tools & Technologies

- **Microsoft Excel** – Data analysis, PivotTables, charts, formulas, and dashboard development.
- **Power Query** – Data cleaning, transformation, and merging datasets.
- **Financial Analytics** – Credit risk assessment and default rate analysis.

## Datasets

The project uses two datasets:

| Dataset | Records | Description |
|---|---:|---|
| Loan Applications | 601 | Loan details, amounts, interest rates, DTI ratios, and repayment status |
| Borrower Profiles | 500 | Borrower demographics, income, credit scores, and employment details |

The datasets were merged using `borrower_id` to create a unified analysis dataset.

## Analysis Performed

The analysis focuses on four major business questions:

1. **Credit Score Analysis:** How do credit score ranges influence loan default rates?
2. **DTI Analysis:** How does the Debt-to-Income (DTI) ratio affect borrower default risk?
3. **Loan Purpose Analysis:** Which loan purposes are associated with higher default rates?
4. **Employment Analysis:** How do employment status and years of employment relate to loan defaults?
