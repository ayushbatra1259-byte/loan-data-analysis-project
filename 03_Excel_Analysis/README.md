# Excel Analysis

## Overview

This folder contains the complete Excel-based analysis of the Loan Data Analysis Project. It demonstrates how raw loan application and borrower profile datasets were transformed into meaningful insights using Microsoft Excel and Power Query.

## Analysis Workflow

1. **Data Preparation:** Imported loan application and borrower profile datasets.
2. **Data Cleaning:** Cleaned and transformed the datasets using Power Query.
3. **Data Integration:** Merged both datasets using a common Borrower ID.
4. **Data Analysis:** Examined default patterns across credit scores, DTI ratios, loan purposes, and employment duration.
5. **Visualization:** Created PivotTables, charts, and KPI calculations.
6. **Dashboard Development:** Built an interactive dashboard to present key credit risk indicators and business insights.

## Key Deliverables

- Cleaned and merged loan dataset.
- Excel analysis and supporting calculations.
- Default rate analysis across different borrower segments.
- Interactive Excel dashboard.
- Key findings and business recommendations.

## Key Objective

To use Excel-based financial analytics to identify high-risk borrower segments, understand loan default patterns, and support better credit risk assessment and lending decisions.

**Tools Used:** Microsoft Excel | Power Query | PivotTables | Excel Charts | Financial Analytics
