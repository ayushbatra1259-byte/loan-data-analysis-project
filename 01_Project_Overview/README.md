# Project Overview

The **Loan Data Analysis Project** aims to identify the key factors influencing loan defaults by analyzing borrower profiles and loan application data using Microsoft Excel.

The project involves two separate datasets: Loan Applications and Borrower Profiles. Using **Power Query**, both datasets were cleaned, transformed, and merged into a unified dataset for comprehensive analysis.

The analysis examines the relationship between loan defaults and various borrower and loan characteristics, including credit score ranges, Debt-to-Income (DTI) ratios, loan purposes, and employment duration.

An interactive Excel dashboard was developed to visualize default patterns, monitor key risk indicators, and compare the overall default rate against the company's target of 12%.

**The primary objective** is to transform raw loan data into actionable business insights that help identify high-risk borrower segments, improve credit risk assessment, and support informed lending decisions.
